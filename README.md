# Flort engine (*Flor*is *T*immermans)

Flort is a semi-game engine made in rust, the idea behind it is that it compiles code into bytecode, and at runtime uses that bytecode to run the game thats made.

The bytecode is generated from python, js and java, which are all compiled by a compiler and for every language a config file, atleast that's the concept
